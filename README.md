## 作ったきっかけ

就職活動では、企業ごとにマイページのIDとパスワードがメールで届きます。ログインするたびに次の操作を繰り返していました。

> メールを開いてIDをコピー → ログインページで貼り付け → メールに戻ってパスワードをコピー → ログインページで貼り付け

何社も受けるので、この往復を毎回繰り返すことになります。そのうちに「コピーしておける場所がいくつもあれば、往復しなくて済むのに」と考えるようになり、Clip5 を作りました。

きっかけは就職活動でしたが、ほかの場面でも使える便利な機能だと思っています。まだできることは少ないですが、これからもっと便利にしていきます。

## できること

- **5つのスロットに保存**：文字を選択して `Control + Shift + 1〜5`
- **番号を指定して貼り付け**：入力欄で `Control + 1〜5`
- **サイドパネルで一覧を確認**：ツールバーのアイコンから開くと、保存した内容の確認・コピー・消去ができます。ページを操作してもパネルは閉じません
- **貼り付けは `Cmd + Z` で取り消せる**
- 操作の結果を画面右下に短く表示

## 使い方

| 操作 | キー |
|---|---|
| 選択した文字をスロットに保存 | `Control + Shift + 1〜5` |
| スロットの中身を貼り付け | 入力欄で `Control + 1〜5` |
| 一覧を見る・コピー・消去 | ツールバーの Clip5 アイコン |

※ 現在は macOS の Chrome で動作を確認しています。

## インストール

Chrome ウェブストアにはまだ公開していないため、次の手順で読み込みます。

1. このリポジトリをダウンロードして展開する（緑の「Code」→「Download ZIP」）
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」から、展開したフォルダを選ぶ
5. 開いているタブを再読み込みする

## 工夫したところ

- **貼り付けを `Cmd + Z` で取り消せるようにした**
  入力欄の値を直接書き換えると、取り消しの履歴が残りません。`execCommand("insertText")` を使って、普通に入力したのと同じ扱いにしています。
- **機能を削ってシンプルにした**
  最初は「入力欄の外で `Control + 数字` を押すとコピーになる」機能もありました。しかし、試してみると場所によって動きが変わるのは分かりにくく、コピーはサイドパネルのボタンでもできます。そこでこの機能は削り、`Control + 数字` は「貼り付け」だけにしました。
- **特殊な入力欄にも対応した**
  一部のサイトで使われる Shadow DOM の中の入力欄も、フォーカスをたどって見つけるようにしています。
- **ページを操作しても一覧が消えないようにした**
  最初はポップアップで作りましたが、ページをクリックすると閉じてしまいます。そこでサイドパネルに変えました。

## 苦労したこと

完成後、ショートカットがまったく反応しない問題が起きました。原因になりそうなものを一つずつ確かめました。

1. 拡張機能を再読み込みしたあと、開いていたタブとのつながりが切れていないか
2. macOS のショートカット（デスクトップ切り替え）とぶつかっていないか
3. 日本語入力がキーを先に受け取っていないか（英数入力で試す）
4. サイト側がキー入力を止めていないか

どれも原因ではありませんでした。そこで、拡張機能が読み込まれたことを画面に表示する確認用のコードを入れて調べました。その結果、**試していたのが Chrome の「新しいタブ」の画面で、ここでは拡張機能が動かない**ことが分かりました。見た目は Google のページでも、中身は Chrome の内部ページだったのが原因です。

## 注意点と今後の課題

**保存した内容は、暗号化せずにブラウザ内（`chrome.storage.local`）に保存しています。** サイドパネルにもそのまま表示されます。パスワードを保存する場合は、この点に注意してください。

今後やりたいこと：

- [ ] パスワードなどをサイドパネルで伏せ字にする

- [ ] スロットの数を増やせるようにする

## 使用技術

- JavaScript
- Chrome Extensions（Manifest V3）
  - Content Scripts（キー入力の監視、貼り付け）
  - `chrome.storage`（スロットの保存と、タブ・サイドパネル間の同期）
  - `chrome.sidePanel`（一覧表示）
- HTML / CSS（ダークモード対応）
